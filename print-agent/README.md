# 本地打印助手（针式打印机直打）

## 这是什么

一个跑在**打印机插着的那台电脑**上的小工具。装了它之后，在网页「打印中心」点
**「针式直打」**，票据会**直接从针式打印机出来，全程不弹浏览器打印对话框**。

- 纯 PowerShell，**免安装**（Windows 10/11 自带 PowerShell）
- 只监听本机 `127.0.0.1:18181`，不对外网开放，其他电脑访问不到
- 纸型和边距由助手锁死（按网页里的打印参数），不会因为浏览器缩放而跑偏
- 支持批量连续打印：一次点「针式直打（N张）」，逐张出票

> **和服务器无关**：助手只听本机 127.0.0.1。服务器在 Mac 上、还是在公网，都不影响。
> 带着电脑和打印机去外地，只要那台电脑能打开系统网页，打印流程完全一样。

---

## 怎么用（首次 3 步）

### 第 1 步：确认打印机

Windows「设置 → 蓝牙和其他设备 → 打印机和扫描仪」：

1. 确认针式打印机已装好驱动，能看到；
2. 把它设为**默认打印机**；
3. **在驱动里建一个 180 × 210mm 的纸张表单**（这一步很重要）：
   控制面板 → 设备和打印机 → 选中针式打印机 → 顶部「打印服务器属性」→
   「表单」选项卡 → 勾选「创建新表单」→ 表单名填 `Receipt180x210` →
   宽度 `18.00 cm`、高度 `21.00 cm` → 保存。
   然后在打印机「打印首选项 → 纸张/尺寸」里选它。
   > 为什么要建：打印接口只认驱动里**已存在**的纸张表单。没有对应表单时，
   > 驱动会忽略程序指定的尺寸、回退到自己的默认纸（实测 Microsoft Print To PDF
   > 会回退成 A4）。助手会按尺寸自动匹配驱动里的表单，匹配到才生效。

### 第 2 步：启动助手

把 `print-agent` 整个文件夹拷到那台电脑（放桌面就行），双击：

```
start-agent.bat
```

会弹出一个黑窗口，显示：

```
打印助手 v1.0.0 启动中… Windows=True 可打印=True
默认打印机：EPSON LQ-630K
已就绪：http://127.0.0.1:18181   （保持本窗口开着，关掉即停止打印服务）
```

**这个窗口要一直开着**，关掉 = 停止打印服务。

> 如果显示「可打印=False」，说明加载打印模块失败，窗口里会有 `[警告]` 字样，
> 把那行报错发我即可。

### 第 3 步：自检一次

双击 `selftest.bat`，打印机会吐出一张写着「打印助手自检」的纸。
**出纸了就说明整条路通了。**

然后打开系统网页 → 打印中心 → 看到「**针式直打**」按钮变成可点（不是灰色）就成功了。

---

## 网页上的表现

- 助手没启动时：「针式直打」是**灰色不可点**，鼠标悬停会提示你先启动助手；
  此时仍可用右边的「浏览器打印」。
- 助手启动后：按钮**高亮**，显示默认打印机名字；每 8 秒自动探测一次，不用刷新页面。
- 点「针式直打（N张）」：逐张出票，完成后右下角提示「已直送针式打印机 N 张」。

## 出问题怎么查

| 现象 | 原因 / 处理 |
|---|---|
| 网页上「针式直打」一直是灰的 | 助手没启动，或窗口被关了；双击 `start-agent.bat` |
| 提示「找不到打印机：xxx」 | 打印机名不对；把系统里的默认打印机设好，或告诉我打印机名称 |
| 纸张位置整体偏移 | 在网页「打印中心 → 打印参数」里微调上/左/右边距，改完立即生效 |
| 打出来是空的 / 乱码 | 打印机驱动问题；先跑 `selftest.bat` 确认助手能出纸 |
| 想换端口 | `powershell -ExecutionPolicy Bypass -File print-agent.ps1 -Port 18281`（同时要改网页里的端口） |

日志在同目录 `print-agent.log`，出问题把这个文件发我。

## 文件说明

| 文件 | 作用 |
|---|---|
| `start-agent.bat` | 启动助手（日常就双击这个） |
| `selftest.bat` | 打一张测试页，验证通路 |
| `print-agent.ps1` | 助手主体：HTTP 服务 + 指令解析（跨平台） |
| `print-gdi.ps1` | Windows 专用：GDI+ 把票据画到打印机 |
| `print-agent.log` | 运行日志（自动生成） |

## 通信协议（给开发者看的）

网页 `POST http://127.0.0.1:18181/print`，`Content-Type: text/plain`（用 text/plain
是为了避开浏览器 CORS 预检），body 为 JSON：

```json
{
  "printer": "",
  "copies": 1,
  "paper": { "widthMm": 180, "heightMm": 210 },
  "ops": [
    { "t": "rect", "x": 13, "y": 5, "w": 154, "h": 8 },
    { "t": "text", "x": 14, "y": 5, "w": 152, "h": 8, "text": "收款收据",
      "size": 9, "bold": true, "align": "center" },
    { "t": "line", "x1": 13, "y1": 60, "x2": 167, "y2": 60 }
  ]
}
```

- 所有坐标单位为**毫米**，原点在纸张左上角
- `t` 支持 `text` / `rect` / `line`
- 另有 `GET /health`（探活）和 `GET /printers`（列出打印机）
