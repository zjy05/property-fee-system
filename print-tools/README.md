# 打印工具（针式三联）

## 一、静默打印启动器（零安装，推荐先用这个）

文件：`Windows-静默打印启动器.bat`

**它解决什么**：原来点「打印」会弹出浏览器的打印对话框，每次都要手动选打印机、
选「实际大小 100%」。用这个启动器打开系统后，点「打印」**直接出纸，不弹窗**。

**怎么用**

1. 把 `Windows-静默打印启动器.bat` 拷到收费员那台 Windows 电脑（桌面即可）。
2. **首次使用前先做一次设置**（只做一次）：
   - Windows「设置 → 蓝牙和其他设备 → 打印机和扫描仪」→ 把针式打印机设为**默认打印机**；
   - 打开该打印机「打印首选项 → 纸张/尺寸」→ 选或新建 **180 × 210 mm**（三联纸）；
   - 在浏览器里正常打印一次，把「纸张大小 = 180×210mm」「缩放 = 100%」选好，让浏览器记住。
3. 之后每次双击这个 .bat 就能用，点「打印」直接送纸。

**换地址**：默认打开 `http://127.0.0.1:4000`（本机 Docker）。
要打开公网地址，把网址拖到 .bat 上，或右键 .bat → 编辑，改掉里面的 `URL`。

**注意**
- 用的是 Edge 或 Chrome（先找 Edge，找不到再用 Chrome），需要电脑上装了其中之一。
- 启动器会用一个独立浏览器配置目录（`%LOCALAPPDATA%\PropertyFeePrint`），
  不会影响你平时用的浏览器。
- 如果打印位置整体偏移，在系统「打印中心 → 打印参数」里微调上/左/右边距即可，
  改完立即生效。

## 二、本地打印助手（进阶，后续可做）

如果你觉得浏览器方案还是不够稳（比如想做到易达那种「连续批量、纸型完全锁死、
不受浏览器影响」），可以再上一个本地打印助手：

- 在**打印机插着的那台电脑**上放一个小工具（免安装，双击启动）；
- 网页点「打印」→ 助手收到票据数据 → 用 Windows 打印接口直接输出到针式打印机；
- 全程无浏览器对话框，纸张/边距由助手锁死，适合大批量套打。

**和服务器无关**：助手只听本机 `127.0.0.1`，服务器在哪、你人在哪都不影响。
带着电脑和打印机去外地，只要那台电脑能打开系统网页，打印流程完全一样。
